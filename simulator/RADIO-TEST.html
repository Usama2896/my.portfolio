AL JEHAD FPV OBSTACLE COURSE · V0.5 · OFFLINE DIAGNOSTIC

See what your radio sends.

This page reads a controller connected to this computer. It does not send anything to the cloud and does not control the simulator. You can keep it open beside the game.

Connect the radio in USB Joystick/HID mode, click Activate, then move a stick.

Live raw axes

Move one stick direction at a time. Check which A-number changes. A throttle often reads −1 at one end and +1 at the other. Browser axis order may differ from the simulator's order.

Buttons / switches

No controller selected.

Report to share in chat

Click Copy report. If copying is blocked, click the box below, press Ctrl+A then Ctrl+C, and paste it into the chat. Nothing is uploaded automatically.

If nothing appears

Use a USB data cable and select USB Joystick/HID on the radio. Keep this browser page focused and move a stick after clicking Activate. Some browsers restrict the Gamepad API on local files. If the page says unsupported, use the simulator's Copy remote diagnostic report button instead. Do not install random drivers.

To run a flight, open AlJehadFPV.exe. This page only checks input. You can use Alt+Tab to switch between it and the simulator.
